Neon Strike

A fast 2D arcade battler — pilot a strike craft through neon combat zones, chain combos, and chase the high score. My first game, currently being built.

game2d arcadegodot

Planned Technical Architecture

Engine: Godot 4 (free, open source) — one project exports to Android, PC, and Web. The module design for Neon Strike:

Core Loop

Fixed-timestep game loop driven by a state machine: menu → playing → paused → game over.

Rendering

2D sprite renderer with particle effects and screen shake for combat feel.

Physics

Lightweight arcade physics — hitboxes, collision layers, and projectile motion.

Input

Unified touch + keyboard input layer, so the same build plays on phone and PC.

Audio

Mixed sound effects with an adaptive music layer that intensifies in combat.

UI / HUD

Menus, health bars, score popups, and combo counters.

Save System

Local JSON saves for progress and high scores — no account needed.

Build Pipeline

One-click exports to Android (APK) and Web from the same project.
